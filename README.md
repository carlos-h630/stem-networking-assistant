# PeerPath

Finding your path in STEM shouldn't rely on luck. **PeerPath** is a web-based networking and mentorship platform designed to connect community college transfer students directly with alumni working in education, policy, research, and advocacy.

## Overview

PeerPath bridges the mentorship and resource gap for underrepresented and transfer students entering STEM fields. Grounded in user research, student interviews, and academic literature review on transfer student retention, the platform provides tailored outreach tools, career pillars, and alumni connections to streamline professional networking.

## Features

* **Alumni Discovery:** Filter mentors by impact pillars (Education, Policy, Community Outreach, etc.) to curate targeted networking connections.
* **Outreach Pipeline:** Track mentorship and networking contacts from initial outreach to completed conversations.
* **Resume Extractor & Highlights:** Pull experience hooks from resumes to power personalized outreach messages.
* **Secure Authentication & Account Management:** Powered by Supabase Auth for secure sign-ups, password recovery, and role-based data isolation.

## Technology Stack

* **Frontend:** HTML, Tailwind CSS, JavaScript (Vanilla JS)
* **Backend & Database:** Supabase (PostgreSQL, Auth)
* **Hosting & Deployment:** Vercel
* **Development Environment:** Cursor AI IDE
